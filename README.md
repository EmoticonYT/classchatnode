Admin Dashboard,
Audio Calling,
Private Messaging,
Friends System,
User Accounts,
(Broken) Push Noticications for calls and PMs,
Sort posts by classes

# 1. Installation

> [!NOTE]
> Make sure you have Node and Git installed!

1. Run the command `git clone https://github.com/emoticonyt/classchatnode`

2. Next, run the command `cd classchatnode`

3. Now, run the command `unzip FOlders.zip`

4. Then, run the command `npm install`

5. Finally, run the command `node server.js`

If you did everything right, than you should get an output in your terminal with the port.
